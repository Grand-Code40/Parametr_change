# Проверка дизайна A/B-эксперимента

Учебная работа по проверке корректности эксперимента. Сгенерированы уникальные данные для 4907 пользователей (seed = 648345).

## Файлы

- `experiment_analysis.ipynb` — ноутбук с кодом, результатами и аналитическими выводами.
- `experiment_data.csv` — исходные данные эксперимента (4907 строк).
- `analyze_experiment.py` — отдельный Python-скрипт анализа.

## Запуск

Положите ноутбук и CSV в одну папку, установите `numpy`, `pandas`, `scipy`, `matplotlib` и запускайте ячейки сверху вниз. Аналогично можно запустить `python analyze_experiment.py`.

## Результат

- SRM: p-value = 9.81e-22.
- Дисбаланс `pre_activity`: p-value = 3.53e-06.
- Частота ошибок: control 0.968%, test 2.314%, p-value = 0.000244.

**Итог:** эксперимент невалиден; тест необходимо остановить, исправить ошибки и перезапустить.

Бонусный раздел показывает балансировку групп по активности. Он не заменяет исправление рандомизации и повторный запуск эксперимента.
